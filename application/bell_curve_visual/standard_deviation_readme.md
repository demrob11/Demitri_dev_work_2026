# 📊 Standard Deviation Viewer

This Python script displays a full-screen graphical and textual explanation of **standard deviation** using `tkinter` and `matplotlib`. It is designed to help visualize and understand how standard deviation reflects the spread of data in a normal distribution.

---

## ✅ Features

- Full-screen GUI window
- Bell curve (normal distribution) with mean (μ) and standard deviation (σ) labeled
- Side-by-side layout: graph + explanation
- Press `Escape` to close the app

---

## 📦 Requirements

- Python 3.7+
- matplotlib

Install required packages:

```bash
pip install matplotlib
```

---

## 🚀 How to Run the Script

### 1. Save the Script

Create a Python file named, for example:

```bash
standard_deviation_viewer.py
```

Paste the script contents into this file.

### 2. Run the Script

In a terminal, run:

```bash
python standard_deviation_viewer.py
```

### 3. Exit

- Press the `Escape` key to exit full-screen mode and close the app.
