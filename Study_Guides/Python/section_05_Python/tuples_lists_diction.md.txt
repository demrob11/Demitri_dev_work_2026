## 🧠 Understanding Tuples, Lists, and Dictionaries in Python

This guide will help you clearly understand what **tuples**, **lists**, and **dictionaries** are in Python — how they're structured, what they store, and how you use them.

---

## 🔷 What is a Tuple?

A **tuple** is an **ordered**, **immutable** (unchangeable) collection of items.

### 📌 Key Properties:
- Defined using **parentheses**: `()`
- Stores a **sequence** of items
- Items can be of **any type** (numbers, strings, etc.)
- **Cannot be changed** once created

### ✅ Example:
```python
my_tuple = (10, 20, 30)
print(my_tuple[0])  # Output: 10
```

### 🔄 Why Use Tuples?
- Faster than lists
- Useful when you want **fixed data**
- Often used for **function returns** or **multiple assignment**

```python
name, age = ("Alice", 30)  # tuple unpacking
```

---

## 🟩 What is a List?

A **list** is an **ordered**, **mutable** (changeable) collection of items.

### 📌 Key Properties:
- Defined using **square brackets**: `[]`
- Stores a sequence of items
- Items can be added, removed, or modified

### ✅ Example:
```python
my_list = [10, 20, 30]
my_list.append(40)
print(my_list)  # Output: [10, 20, 30, 40]
```

### 🔄 Why Use Lists?
- When your data needs to change (grow, shrink, update)
- Ideal for loops, iteration, stacking items, etc.

---

## 🟨 What is a Dictionary?

A **dictionary** is an **unordered** collection of **key-value pairs**.

### 📌 Key Properties:
- Defined using **curly braces**: `{}`
- Access values using **keys**, not indexes
- Keys must be **unique and immutable** (strings, numbers, etc.)
- Values can be **anything**

### ✅ Example:
```python
my_dict = {
    "name": "Alice",
    "age": 30,
    "location": "NYC"
}

print(my_dict["name"])  # Output: Alice
```

### 🔄 Why Use Dictionaries?
- Store data with **labels**
- Great for **structured or named data** (e.g. user info, settings, etc.)

---

## 📊 Tuple vs List vs Dictionary Comparison

| Feature        | Tuple                    | List                      | Dictionary                        |
|----------------|---------------------------|---------------------------|------------------------------------|
| Syntax         | `(item1, item2)`          | `[item1, item2]`          | `{key1: value1, key2: value2}`     |
| Ordered?       | ✅ Yes                    | ✅ Yes                    | ❌ (order preserved in 3.7+)        |
| Indexed?       | ✅ Yes                    | ✅ Yes                    | ❌ Uses keys                       |
| Mutable?       | ❌ No                     | ✅ Yes                    | ✅ Yes                             |
| Use case       | Fixed group of values     | Dynamic sequence          | Labeled data                      |

---

## 🧪 Bonus: Using Them in Functions

```python
def demo(*args, **kwargs):
    print("Tuple:", args)      # extra positional args
    print("Dictionary:", kwargs)  # extra keyword args

demo(1, 2, 3, a=10, b=20)
# Output:
# Tuple: (1, 2, 3)
# Dictionary: {'a': 10, 'b': 20}
```
